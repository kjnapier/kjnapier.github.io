About

Log entry · pilot profile

I find the faintest worlds beyond Neptune.

Most of my work is discovering trans-Neptunian objects in data from space telescopes, using shift-and-stack searches to pull out objects far fainter than any single image can show. I also study the solar system with large ground-based telescopes, write the software that makes these searches possible, and do some theory on how the outer solar system came to look the way it does.

    Shift and stack

    Primary technique · try it

    The objects I look for are too faint to see in any single image. Shift-and-stack adds many exposures together after shifting each one along a guessed path across the sky. Guess wrong and the object smears into the noise. Guess right and its light piles up in one spot while the noise averages away. Each mode below hides an object in the same twelve noisy frames, with one, two or three unknowns to guess. Drag the sliders, or run the grid search and let it try every guess.
